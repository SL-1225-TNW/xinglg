# 苔芽农场 · 星露谷

> 仓库地址：https://github.com/SL-1225-TNW/xinglg

原生 HTML / CSS / JavaScript 的像素风种田小游戏。**双击 `index.html` 就能玩**，
不需要 npm、不需要起服务器、不访问任何 CDN（`file://` 直接可用）。

主角是橙色像素小螃蟹 **Clawd**。一天的动作循环是：早晨从家出门 → 看田浇水 →
采集或钓鱼 → 回家整理 → 上床睡觉。

## 怎么分享给别人玩

**方式一：单文件（推荐给不熟悉 Git 的朋友）**

仓库里的 [`苔芽农场-单文件版.html`](苔芽农场-单文件版.html) 是把 `styles.css` 与 `game.js`
全部内联后的**单个 HTML 文件**，约 277KB、零外部依赖。把这个文件发过去（微信/QQ 文件传输、
网盘、U 盘都行），对方**双击就能玩**，不用装任何东西、不用联网、解压都不需要。

这个文件由 `node tests/build-single-file.mjs` 生成，改完游戏代码后重新跑一次即可；
`node tests/single-file-smoke.mjs` 会真的用 `file://` 打开它、走几步、翻一块土，
确认不是"看起来能打开"的空壳。

**方式二：直接给网址（手机上也能开，手机浏览器直接玩）**

```
https://sl-1225-tnw.github.io/xinglg/
```

站点由 `.github/workflows/pages.yml` 自动部署：**每次推送 `main` 都会重新发布**，
不用手动操作。页面上还放了 `苔芽农场-单文件版.html`，朋友可以在网页里直接下载那个单文件。

> Pages 站点需要在仓库设置里首次启用一次（`Settings` → `Pages` → `Source` 选
> `GitHub Actions`）。之后全部由工作流接管，GitHub 的 token 没有权限做这第一次启用。

**方式三：直接给仓库链接**

让朋友打开 https://github.com/SL-1225-TNW/xinglg ，点 `Code` → `Download ZIP`，
解压后双击 `index.html`。

## 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | 方向键 或 `W` `A` `S` `D` |
| 使用工具（锄地 / 播种 / 浇水 / 收获…） | `空格`，作用在**朝向或脚下相邻**的格子 |
| 交互（进门、开箱、交付委托…） | `E` |
| 切换快捷栏 | `1` – `9`（第 9 格是小铲子） |
| 背包 / 制作 / 任务 | `B` / `C` / `J` |
| 全境地图（再次按下关闭） | `M` |
| 暂停菜单（睡觉、保存、导入导出存档） | `Esc` |

触屏设备会自动显示方向键和「使用工具 / 交互」按钮，文案也会跟着切换。

## 有什么内容

- **全境地图**：西北角的苔芽农场、中央白蔷薇城，以及小镇、河湾、葡萄园、森林、山口、磨坊，共 8 个地点。点击查看介绍与开放状态；新增区域仅为规划，尚未建造，不提供传送。手机从暂停菜单打开。

本轮已修复睡觉后时间未重置、引导期间铲除断链、家具 E 提示偏移及快捷栏工具图标；移除地图地点导航标记，保留委托栏。协作开发请从 `main` 拉取；游戏入口为 `index.html`，逻辑在 `game.js`，样式在 `styles.css`。专项验证使用 `node tests/run-review-fixes.mjs` 和 `node tests/run-world-map.mjs`（需要安装 `tests` 中的 Playwright 依赖与浏览器）。修改游戏后请重新生成单文件版。

- **三种作物**（萝卜 / 土豆 / 草莓）：刚播种、幼苗、生长中、成熟四个阶段各有不同的
  像素轮廓；只有成熟时才出现低频收获提示；草莓收获后保留植株进入再生期。
  干土和湿土颜色明显不同，刚浇过的地会有一圈水花。
- **可走进去的农舍室内**（16×12 格）：门口按 `E` 进入，屋内有床、储物箱、日历、
  农场手册四项真正可用的家具，全部参与碰撞。床睡觉会结算一天并自动存档。
- **农场 / 小镇 / 河边**三个场景、四个委托、修桥、真实钓鱼、制作与交易。
- **池塘里有 5 条会游动的鱼**：限定在水域内游动、摆尾、转向、偶尔停顿；
  纯环境表现，不能钓、不解锁钓竿、不影响委托顺序。
- **新手引导 + 今日待办**：9 步引导只提示下一步，进度从真实操作推导并写进存档，
  可以随时暂停 / 跳过 / 继续；旧存档不会突然弹教程。待办按地块真实水分与成熟度统计。
- **大屏自适应**：桌面按 0.5 步进放大（不再锁死在 1x/2x/3x）；
  2000×1100 以上启用沉浸式布局，顶栏 / 引导条 / 快捷栏浮在画面上，画布几乎满屏。
- **小铲子（快捷栏第 9 格）**：种错了可以铲掉改种。当天刚播下（还停在第 0 天）的那株
  铲掉会**完整退还种子**，已经长过一天的不退——否则"播种 + 铲除"能无限刷种子。
  铲一株耗 2 点体力；新手引导走完之前不能铲，避免把引导第 3 步要的那株作物铲没了。
- **委托方向指示**：任务板、小桥施工点、种子铺、出货箱都会标出方向和距离。
  目标在同一场景且在视口内时画金色四角标（当前进行中的那条最亮）；
  在视口外或别的场景时，改为贴着屏幕边缘画箭头并写"任务板（去小镇） 右方 22 格"。
- **今日结算逐页演出**：睡觉后不再是干巴巴一页汇总，而是按「出货与收入 → 田里的变化 →
  果酱罐 → 委托进展 → 天气与明天」分页呈现，每页有步骤指示，翻到最后开始新的一天。
  每天还会往收成记录里留一条（最多 7 天），从日历窗的「收成记录」随时回看。

## 目录结构

```

第三版提示词.md      本轮的需求说明

tests/              Playwright 自动化试玩台（仅开发期使用，游戏本体不依赖）

```

## 跑自动化测试

需要 Node 与 Playwright：

```bash
cd tests
npm install          # 只装测试依赖，游戏本体不需要

cd ..
node tests/run-v3.mjs              # 第三版功能，112 项
node tests/run-guide.mjs           # 新手引导 / 今日待办，59 项
node tests/run-ui.mjs              # 桌面 / 竖屏 / 横屏 / 大屏布局，93 项
node tests/run-fixes.mjs           # 修复回归（含铲除 / 委托方向 / 分页结算），48 项
node tests/run-edge.mjs            # 边界与存档，137 项
node tests/run-main.mjs            # 正常主线跑到第 14 天，120 项
node tests/canvas-size.mjs         # 七种分辨率的画布尺寸测量
node tests/landscape-shot.mjs      # 横屏手机布局取证
node tests/shots-fixes.mjs         # 铲除 / 委托方向 / 结算演出的画面取证（只截图，不计入断言）
node tests/build-single-file.mjs   # 重新生成单文件版
```

测试全部用**真实键鼠**驱动浏览器，不注入夹具状态；边界场景确实需要预置存档时，
会在用例名和报告里明确标出。`output/playwright/` 里的截图和 `v3-pond-fish.webm`
录像都是这些脚本跑出来的真实画面。

## 已知限制

- 室内只有农舍一间；小镇店铺与作坊保持原有的弹窗交互。
- 池塘鱼是纯装饰，不能钓、不喂、不繁殖。
- 沉浸式大屏布局下快捷栏会压住画面底部约 100px，这是"几乎满屏"的既定取舍。
- 收成记录只留最近 7 天，而且只记睡觉结算的那一次；在种子铺当场卖东西的收入不进球。
- 方向指示最多同时画 4 个目标（当前委托 + 后续交付点 + 种子铺 / 出货箱两个地标）。
- 作物阶段对比图是用预置状态取的画面，不是自然等 6 天拍下来的；
  真实生长链路由 `run-edge` 与 `run-main` 用正常操作覆盖。

更详细的逐项验收结果见 [`试玩报告.md`](试玩报告.md)。
