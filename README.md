# 苔芽农场 · 星露谷

> 仓库地址：https://github.com/SL-1225-TNW/xinglg

原生 HTML / CSS / JavaScript 的像素风种田小游戏。**双击 `index.html` 就能玩**，
不需要 npm、不需要起服务器、不访问任何 CDN（`file://` 直接可用）。

主角是橙色像素小螃蟹 **Clawd**。一天的动作循环是：早晨从家出门 → 看田浇水 →
采集或钓鱼 → 回家整理 → 上床睡觉。

## 怎么玩

| 操作 | 按键 |
|---|---|
| 移动 | 方向键 或 `W` `A` `S` `D` |
| 使用工具（锄地 / 播种 / 浇水 / 收获…） | `空格`，作用在**朝向或脚下相邻**的格子 |
| 交互（进门、开箱、交付委托…） | `E` |
| 切换快捷栏 | `1` – `8` |
| 背包 / 制作 / 任务 | `B` / `C` / `J` |
| 暂停菜单（睡觉、保存、导入导出存档） | `Esc` |

触屏设备会自动显示方向键和「使用工具 / 交互」按钮，文案也会跟着切换。

## 有什么内容

- **三种作物**（萝卜 / 土豆 / 草莓）：刚播种、幼苗、生长中、成熟四个阶段各有不同的
  像素轮廓；只有成熟时才出现低频收获提示；草莓收获后保留植株进入再生期。
  干土和湿土颜色明显不同，刚浇过的地会有一圈水花。
- **可走进去的农舍室内**（16×12 格）：门口按 `E` 进入，屋内有床、储物箱、日历、
  农场手册四项真正可用的家具，全部参与碰撞。床睡觉会结算一天并自动存档。
- **农场 / 小镇 / 河边**三个场景、四个委托、修桥、真实钓鱼、制作与交易。
- **池塘里有 5 条会游动的鱼**：限定在水域内游动、摆尾、转向、偶尔停顿；
  纯环境表现，不能钓、不解锁钓竿、不影响委托顺序。
- **新手引导 + 今日待办**：9 步引导只提示下一步，进度从真实操作推导并写进存档，
  可以随时暂停 / 跳过 / 继续；旧存档不会突然弹教程。待办按地块真实水分与成熟度统计。
- **大屏自适应**：桌面按 0.5 步进放大（不再锁死在 1x/2x/3x）；
  2000×1100 以上启用沉浸式布局，顶栏 / 引导条 / 快捷栏浮在画面上，画布几乎满屏。

## 目录结构

```
index.html          页面骨架
styles.css          全部样式（含横屏与大屏沉浸式布局）
game.js             游戏逻辑（原生 JS，无依赖）
第三版提示词.md      本轮的需求说明
试玩报告.md          实操验收报告：改了什么、跑了哪些流程、还有哪些限制
tests/              Playwright 自动化试玩台（仅开发期使用，游戏本体不依赖）
output/playwright/  验收过程中产出的真实游戏截图与录像
```

## 跑自动化测试

需要 Node 与 Playwright：

```bash
cd tests
npm install          # 只装测试依赖，游戏本体不需要

cd ..
node tests/run-v3.mjs              # 第三版功能，112 项
node tests/run-guide.mjs           # 新手引导 / 今日待办，54 项
node tests/run-ui.mjs              # 桌面 / 竖屏 / 横屏 / 大屏布局，93 项
node tests/run-fixes.mjs           # 第二版修复回归，22 项
node tests/run-edge.mjs            # 边界与存档，137 项
node tests/run-main.mjs            # 正常主线跑到第 14 天，120 项
node tests/canvas-size.mjs         # 七种分辨率的画布尺寸测量
node tests/landscape-shot.mjs      # 横屏手机布局取证
```

测试全部用**真实键鼠**驱动浏览器，不注入夹具状态；边界场景确实需要预置存档时，
会在用例名和报告里明确标出。`output/playwright/` 里的截图和 `v3-pond-fish.webm`
录像都是这些脚本跑出来的真实画面。

## 已知限制

- 室内只有农舍一间；小镇店铺与作坊保持原有的弹窗交互。
- 池塘鱼是纯装饰，不能钓、不喂、不繁殖。
- 沉浸式大屏布局下快捷栏会压住画面底部约 100px，这是"几乎满屏"的既定取舍。
- 作物阶段对比图是用预置状态取的画面，不是自然等 6 天拍下来的；
  真实生长链路由 `run-edge` 与 `run-main` 用正常操作覆盖。

更详细的逐项验收结果见 [`试玩报告.md`](试玩报告.md)。
