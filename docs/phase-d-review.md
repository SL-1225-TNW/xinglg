# 阶段 D 复审与补修

日期：2026-10-09。基线：main `8cb2ad7`。

本轮对照总规 §34.1 的 D 退出条件“有职业服务与跨地点合同，不只有外立面”。验收范围为五个专业地点的首轮合同、主要选择分支、生产复访、真实内部与操作事务。它不等于整套职业晋升、属性天赋、危机系统已经完成。

## 修复内容

| 原问题 | 现在的行为 |
|---|---|
| 选择酿酒后缺少医舍葡萄汁供货的恢复路径 | 酒窖计划可改做鲜汁；酿酒封存后，每隔七个游戏日可安排下一轮并重新选择用途，医舍访问权限不会被清空 |
| 雨天只有延期入口，延期同日却可以抢收 | 雨天同时提供低产抢收和延期；选择延期须经过一个游戏夜晚才可采收 |
| 封存酒液清空来源计数 | 封存后保留已加工数量，同一批来源不能再次加工；新一轮采收才重置批次计数 |
| 采场累计产量到阈值后永久停产 | 支护后每日采掘一次；累计来源、加工量及采掘日期保存，切料必须有尚未加工的采场来源和真实原石 |
| 未签收货物可能被旧装运按钮覆盖 | 执行时再次检查未结运单；重复点击不会多扣货物或覆盖运单 |
| 处理历史货差会顺带把新运单标成已签收 | 差额处置只更新差额选择与款项，不改变在途货物签收状态 |
| 水利选择只有文案差异 | 工程隔夜验收后才生效：灌溉优先自动为牧场试种田供水，磨坊最多两批，货运加20分钟；通航优先货运减10分钟，磨坊保持原本协定，牧草晴天仍需浇水 |
| 河港追索后的“优先级降低”只有文案 | 追索后每次装运增加10分钟封签复核；补运分支没有这项额外耗时 |
| 与职业 NPC 聊天后缺少事务入口 | 七名专业 NPC 的对话加入对应“职业服务与合同”入口，实际工作仍检查设施距离 |

## 复审方式

`tests/run-phase-d-review.mjs` 覆盖酿酒先行到医舍履约、雨天两种选择、实际跨夜、生产冷却、两种水利方案的真实供水／磨粉／装运差异、运单防重复、存档重载、体力／时间／金币／背包／设施距离拒绝，以及八处重要内部的方向键步行与 E 进门。

手机部分在 844×390 与 390×844 触屏浏览器中检查五个专业地点的操作入口、窗口横向溢出和 NPC 对话事务入口。这不替代实体手机性能验收。

测试以已完成 C 的存档边界和初始资源作为夹具。D 的采收、加工、运单、签收、复诊和跨日通过实际按钮与正常日结算推进。水利影响另使用已验收工程边界夹具来比较两种政策；完整水利施工链由 `run-phase-cde.mjs` 验证。八处室内的可达性测试使用已解锁地区边界；未宣称从农场新档连续自然游玩到所有 D 分支。

## 验收边界

五个地点已具有独立室内、职业服务和相互连接的合同，D 功能基线按专项测试复审。后续仍需补长期岗位责任、完整职业晋升、人物事件、庄园雇工与宴会订单，以及实体手机和从新档开始的长期探索试玩。湿地的生态可视化不足另属 C，不以本次 D 复审宣称已解决。
