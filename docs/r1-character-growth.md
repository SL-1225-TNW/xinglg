# R1 实施与复审 · 角色成长和小镇独立起步

实施：2026-10-12；复审：2026-10-13。基于本地 R0 提交 `62dcb80` 和原有 R1 工作区继续修复；发布结果以对应 Git 提交及 Actions 为准。

## 玩家现在能做什么

顶栏「角色」、键盘 P、手机角色按钮和暂停菜单进入同一窗口。五项属性基础各 5，旧档首次得到 10 个未分配创建点；每次升级再得 1 点。当前开放到 10 级，达到后不囤积溢出经验。创建点在单项 10 以内分配；后续升级点允许继续提高，永久上限 20。

3/6/9 级各得一个天赋点，当前最多 3 点。后续随阶段上限开放到 24 级，总上限 8 点。属性点和天赋点分别守恒。可学习的两个节点是「节省力气」和「均衡饮食」，其他八个首批节点仍只读，不能购买。

洗点在角色页和农舍手册均可预览。首次免费，之后每次 50 金；返还属性点与天赋点各自的余额，不重置每日减免上限，不恢复体力，不删除任务、关系或职业资格。

属性当前用于对应天赋的学习门槛。研究耗时、感知线索、生命上限等直接收益尚未全面接入，界面已说明；这次没有交付个人刀剑或战斗。

## 三条独立新档路线

在 J 委托日志的「小镇入门」查看说明，到小镇任务板旁报名。报名和各步结算均检查真实站位、阶段、时间、体力；远程查看不能执行。所有点位使用小镇已有入口，目标写明地点和下一步。

| 路线 | 实际流程 | 完成结果 |
|---|---|---|
| 工程：松动的公共水泵 | 任务板报名 → 作坊检查 → 任务板核对用水记录 → 作坊借扳手维修试水 → 任务板归档 | 25 金、60 经验、工程路线 +2、工程资历 +1 |
| 商旅：没有署名的货单 | 报名 → 种子铺核来源 → 作坊核收件 → 种子铺领封包 → 作坊签收 → 回任务板交回执 | 25 金、60 经验、商旅路线 +2、贸易资历 +1 |
| 巡林：林缘的足迹 | 报名 → 公开林口调查 → 集市核对见闻 → 林口系警示绳并标安全侧 → 回任务板交报告 | 25 金、60 经验、巡林路线 +2 |

任务工具由委托方借出。商旅封包和回执是不可出售的任务保管状态，不占普通背包；交付后不再持有封包。完成事实、进度、奖励键和路线记录在同一次事务中保存，重复点击和读档不重发。

三条都不依赖修桥、进入森林深处、湿地公共工程、城门证或军事巡防。路线 +2 提供到访引荐，不自动获得接军事任务或指挥军队的权限。已完成项目目前以工作记录和界面结果呈现；更丰富的设备/警示绳视觉变化及后续持续职责留在 R3。

## 本轮修复的实际错误

- 洗点原来把已花天赋加到属性余额、清空未花天赋，且免费标记反转；现分别返还并持久化收费资格。
- 角色页原来调用不存在的 `openCharRespecPreview`，现调用实际预览函数。
- 存档归一化原来把 25 点基础属性算进可分配余额，天赋也未按等级约束；现按等级、创建限制及总预算修正，重复归一化结果一致。
- 森林采集原来在 `charSpendEnergy` 后再次扣体力；现只扣一次。森林和农场均在背包装不下时先拒绝，不扣体力、不多退、不消耗天赋次数、不伤资源节点。
- 采集成功接上每日资源经验，空挥和未采完不发；收获按一次动作发 2 点，不按产物数量放大。
- 每日节省力气次数写回读档账本；按折扣后耗费检查剩余体力。日常委托前三份经验封顶也使用持久化每日计数，重复同一委托不占第二次名额。
- 探索委托的经验发放移到保存前，避免任务已存而奖励尚未保存。
