# 宫殿楼梯与房门复审

2026-10-13。补齐宫城P1的可见通路，保持原有楼层、换层规则与任务入口。

## 玩家怎样走

- 大楼梯现在是完整梯段的石阶，上楼入口在南侧，下楼入口在北侧。平台画有箭头，旁边写明目的楼层，以及按E／手机交互的操作。二层上楼、下楼各用一条梯段；一层和三层没有对应方向的部分画成平台。
- 一层、二层、三层共18处房间入口有敞开的木门扇、门框、门槛、方向箭头和房名。房门直接步行穿过，在同一层进入房间，不额外开菜单或传送。
- 档案阅览、文书室、正式接待、宴会厅、会客室和客房乙的中段隔断切出实际可走门洞。房间开口与绘制共用数据，其余墙体和家具碰撞保留。
- 服务梯画出梯段、挡杆及“暂未开放”门牌，不表示已有后勤换层路线。

## 实现

`installPalaceWayfinding()`在生成楼层地图前给宫殿专用陈设配置梯段和门洞；`CITY_PROPS.palaceSteps`绘制全长梯段，`palaceRoomDoor`绘制同层敞开门。上下楼提示牌直接跟随原楼梯交互物，并放在其真实站位平台。宫殿不改存档布局版本，旧楼梯坐标、上下楼落点与二层的稳定ID均保留。

## 验证

- `run-palace-wayfinding.mjs`：18扇门用真实方向键双向穿行，同层不误传送；上下楼平台真实E换层，40项。
- `run-palace-layout.mjs`：三层连通、全部交互物站位、楼梯落点与栏杆碰撞，106项。
- `run-palace-floors.mjs`：源文件与单文件从宫苑进出、三层与露台往返，82项；两条原有警告仅说明露台出口的交互类型与旧契约文案不同，可达检查通过。
- `run-palace-mobile.mjs`：390×844及844×390的手机控件与楼梯换层，32项。
- 旧档迁移、公共室内门和离线单文件冒烟另行复跑；新增房门用例已加入本地与GitHub验证入口。
