# M1 前置 · 分段旅行

2026-10-21。范围为 P0-1，沿用 3／7 天离农计划，不宣称第二幕或合法跨封国已完成。

## 玩家走法

芽芽任务板的「长期安排」或 J 主线日志的「分段旅行与照料安排」选择目的地和天数。当天预约、次日抵达，在途从安排面板休息至次日，最后一天回农场；也可取消剩余计划提前返程。雨天先暂停，玩家可接受条件后恢复。照料没有覆盖、途中缺粮或落点不安全时不推进、不记支出。

**P0-2 规则调整（2026-10-21）**：P0-2 按总规 §26.1 把民用资料核验函变成进入四个地区的必经条件。若仍按「持函即公付」一刀切，私人预存、逐日核销与取消退未核销部分这条线就永远没有入口——完整两层 CI 抓到了这条冲突（`run-m1-segment-travel` 源码与单文件两轮失败，日志 `output/p0-2-ci.log`）。现在安排面板把两种付款方式分开列出，由玩家自己选：公付只在持函时可选，没有公共核验任务就只能自费预存。旅行专项的断言未改一行，仍是 76 项，两轮都通过。

账目写入 `farmPlan.journey`，保存日号及三类支出；更换计划前归档最近十二段。主线日志的支付账、长期安排、今日安排和当日结算读取同一事实。旧档没有旅行时补 `null` 与空归档，不补造出行或支付记录，不升存档版本。

同时修复既有回声谷门禁调用旧函数、不认识 `ms1_pine` 而恒拒绝的问题；本轮仍沿用既有通行资格。民用核验函、邻领登记、航路准备的完整合法跨境门禁属于 P0-2。
