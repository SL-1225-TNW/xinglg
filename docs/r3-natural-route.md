# R3 自然新档路线与证据边界

更新：2026-10-16。

## 本轮修复

磨坊、牧场和河港的意见按钮原来只写水利站旧字段，工程方案确认却读取项目台账。玩家实际到访并记录意见后，项目仍认为没有收齐三方意见，无法定案。现在意见按钮写入 `riverbay_gate.opinions`，再由项目记录推导旧字段；按钮是否出现及执行前校验也使用同一份项目事实。现场文案分别说明供水或通航时段。

`tests/run-phase-cde.mjs` 同时检查项目台账和兼容字段中的三方意见。专项 57 项通过；自然新档已实际通过三处意见记录和方案定案。

## 自然路线

`tests/run-r3-natural-entry.mjs` 从清空浏览器存储后的全新游戏开始。开局仅有正常种子、工具和金币；播种、浇水、收获、砍树采石、任务交付、柜台采购、房门与出口、职业操作及睡觉均通过真实键鼠输入和游戏界面推进。

路线依次覆盖：

1. 开局播种八块萝卜、两块土豆，按天气照料并自然跨夜。
2. 交付收成、完成公共水泵入门维修，实际采集木石并修桥。
3. 完成本地货单入门，实际采购并修复磨坊水轮，协商用水、试运行、跨夜验收。
4. 步行进入水利站，完成三处勘测、磨坊实践认证、独立报告、汛前预防性岗位评价、正式岗位与一次性机构拨付。
5. 到磨坊、牧场、河港分别记录意见，核验货单，再回控制室确认兼顾通航方案。
6. 出售多余收成，使用正常任务报酬、日结补助及售货收入购买原料；实际熔炼铁锭、修复森林与矿山入口。
7. 在石灰采场测量、选择采面、支护、采掘，在测量棚切割工程石料。
8. 河港装运，携带实际运单回水利站签收，安装闸件并亲自完成四道工序。
9. 封闸试运行；如自然勘测触发预警，现场检查并加固，随后实际跨夜验收。
10. 接受河港复检合同、备货、装运、水利站签收，等到周期养护到期后实际检视。
11. 通过正常「继续游戏」读档，检查工程、处置记录、合同与养护保留且不重复结算。

`__MOSS__` 仅用于状态断言、地图与路径读取；脚本不直接写入位置、背包、时间、资历、证书或工程进度。清空存储用于建立新档，读档使用正常继续界面。采购与施工之间安排实际休息日。
