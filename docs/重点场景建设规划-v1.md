# 苔芽农场 · 白蔷薇城与周边重点场景建设规划

版本：第一版。日期：2026-10-13。

本规划将宫殿、大学、南门旅馆与驿站、河港工业区、医舍与修道院、市政与商会、农舍及代表住宅，建设为有明确入口、房间用途、人物生活和持续玩法的建筑组。优先深化已有地点，保持城市现有道路和地区关系。

本文是后续施工依据。标为“规划”的房间、楼层、服务和任务尚需实现；已建部分也须按每期范围验收。本文的“建设一期—六期”是建筑施工批次，不替代总体规划的 R0—R5。

## 1. 规划依据与范围

- [游戏总体规划第八版](../游戏总体规划.md)：决定成长、职业、经济和交通规则；本规划服从其玩法边界。
- [白蔷薇城总体规划与建筑设计说明](../白蔷薇城总体规划与建筑设计说明-v2.md)：决定街区关系、建筑风格及城市尺度。
- [宫殿专项建设规划](white-rose-palace-construction-plan.md)：保留欧洲宫廷建筑参考、主楼与侧翼布置及楼层方案。
- [宫殿首期实施记录](palace-p1-contract.md)与[楼梯、房门复审](palace-wayfinding.md)：作为宫殿现有施工基线。
- [城市设施配方表](../城市设施配方表.md)：加工设施采用已有材料与服务规则，新增配方另行核对。

施工范围覆盖建筑外观、入口、室内分区、必要楼层、楼梯、房门、服务位置和人物活动。每个重点场景至少形成一条“到访—办事—结果—再次到访”的完整体验。

现有城市图书馆、学院、旅馆、仓库、锯木厂、铸造车间等已有室内布局或服务，应先盘点再改造。医舍与修道院保留在既有地区；城市工业码头与地区河港分别保留，并通过已有运输业务衔接。

## 2. 总体建设原则

### 2.1 建筑规模由用途决定

| 建筑组 | 空间特征 | 建议楼层与体量 |
|---|---|---|
| 宫殿 | 礼仪中轴、大厅、长廊、庭院、后勤侧翼 | 主楼三层；侧翼按用途分期；地下后勤为后续规划 |
| 大学 | 主院、教学翼、图书馆、实验室、温室 | 主教学楼与图书馆可设两层；实验室和温室以一层为主 |
| 南门旅馆与驿站 | 临街接待、客房走廊、车马后院 | 旅馆两层；邮局、马厩、修车棚以一层为主 |
| 河港工业区 | 长仓、生产车间、装卸场、运输通道 | 多数一层；必要处设局部检修平台或办公室 |
| 医舍与修道院 | 诊疗、病房、回廊、药草庭院、档案 | 医舍先完成一层；修道院按档案及生活需要局部设二层 |
| 议事厅与商会 | 公共柜台、议事室、档案、货样与交接院 | 公共服务一层；会议、档案可设二层 |
| 农舍及代表住宅 | 厨房、工作间、卧室、后院 | 农舍按升级开放二层或阁楼；城市住宅按户型采用一至三层 |

表中为设计上限和方向，实际尺寸、房间数量须在每期施工前以可走通的平面图确定。避免用大量空房间充数，也不为增加楼层改变整个城市尺度。

### 2.2 先让玩家知道往哪走

1. 建筑门口可辨认，入口落点面向通路；门旁显示建筑名称或服务名称。
2. 同层房间优先通过真实门洞步行进入；门框、门扇、门槛和墙体开口必须一致。
3. 楼梯具有完整梯段、上下平台、方向和目的楼层；在实际操作位置提示按键或手机“交互”。
4. 大厅或入口附近放简明楼层牌，只列已经开放的空间。封闭房间明确标注用途及未开放状态。
5. 通过灯光、地毯、铺地、招牌和建筑轮廓引路；地图提供辅助定位。
6. 公共通道、服务通道和私人空间分开。日常服务无需穿过私人房间或未开放区域。

### 2.3 房间要有生活和用途

每个开放房间须说明谁使用、玩家能做什么、何时值得回来。装饰性空间可以承担景观、休憩和叙事作用，但不应显示尚不存在的收费服务或任务承诺。

人物活动先围绕工作、休息和往返路线安排。跨楼层、关门和营业时间改变前，必须验证任务人物仍可找到；关键事务要有柜台、公告或记录入口可查。

## 3. 建设一期：宫殿主楼完善与侧翼施工

### 3.1 现状与目标

宫殿已有独立前庭、三层主楼、画廊和露台。最新本地通路改造补入完整主楼梯和三层共十八处房门，并对服务梯标明未开放。首期继续解决“进门能辨方向、上下楼能找到位置、房间有清楚用途”，再施工侧翼。

整体保留欧洲宫廷建筑的中轴、礼仪厅、连续房间、庭院和后勤分流构思；具体参考与示意图沿用宫殿专项规划。

### 3.2 建筑及楼层安排

| 区域 | 建设用途 | 通行安排 |
|---|---|---|
| 前庭与一层 | 接待、等候、访客登记、公共会客、管家事务 | 主入口直达接待；主楼梯从大厅可见 |
| 二层 | 礼仪大厅、正式会客、画廊及相关议事空间 | 主梯进入礼仪层；画廊入口与返回门清楚对应 |
| 三层 | 起居、书房、客房等生活空间 | 主梯可返回；私人房间根据实际内容开放 |
| 东西侧翼 | 厨房、餐厅、职员办公、侍从及储藏等配套 | 先完成一翼；服务路线连接后勤院，避免穿过礼仪大厅 |
| 后勤院与服务梯 | 物资接收、厨房供应、职员往返 | 相关上下层同时完成后再开放服务梯 |
| 花园、礼拜堂、旧塔 | 散步、人物故事、历史线索 | 分小区域交付；每处具备实际返回路线 |
| 地下后勤 | 酒窖、储藏及维护空间 | 远期保留，待内容与通道一起施工后开放 |

### 3.3 施工顺序与交付

先复核主入口、十八处房门、主楼梯、画廊和露台的自然行走路线；补楼层牌与房间用途。随后完成一处侧翼的厨房—储藏—后勤院循环，再补另一翼和生活细节。花园、旧塔与礼拜堂按实际故事需求推进。

验收须能从城市进入宫殿，找到接待、主梯和目标房间，依次上下三层，并返回城市。玩家在入口得到的楼层说明要与真实开放空间一致；原有宫殿事务、人物和存档入口继续可用。

## 4. 建设二期：大学校园与图书馆

### 4.1 建筑组合

以“白蔷薇大学”为校园整体，现有河岸学院作为教学部门保留。组合为主教学楼、中央院落、图书馆、实验室和植物温室；学生宿舍及周边书店、印刷店、咖啡生活在后续补充。

| 区域 | 房间与用途 |
|---|---|
| 主楼一层 | 接待、课程公告、讲堂、教师会谈；初次到访在这里了解学习入口 |
| 主楼二层 | 研讨室、教师研究室、少量专题学习空间；有实际内容再开放 |
| 图书馆一层 | 借阅或查阅柜台、公共书架、地图资料、安静阅读区 |
| 图书馆二层 | 档案、专题资料与研究桌；与已有资料权限及任务条件对应 |
| 实验室 | 植物、矿物、机械研究按当前可支持的主题分区，保留材料桌和样本存放位置 |
| 温室与院落 | 植物观察、样本来源说明、师生休息和校园往返 |

### 4.2 路线与玩法

校园入口先到接待或院落，院落能辨认讲堂、图书馆和温室方向。图书馆楼梯设在查阅柜台附近，实验室使用独立入口，研究材料不经安静阅读区搬运。

本期先交付一条完整学习或研究体验，例如“接待了解主题—查阅资料—观察或提交样本—得到可查的结果”。后续课程、长期研究和资历规则服从总体规划；每座教学建筑采用不同用途，避免重复书架和同类对话。

验收包括自然找到教室和资料柜台、往返两层、研究结果保存，以及原有图书馆、学院和温室服务继续可用。宿舍在人物生活和住宿规则准备好后单独施工。

## 5. 建设三期：南门旅馆、驿站与车马院

### 5.1 空间安排

- **旅馆一层**：前台、等候处、公共餐厅、厨房、通往客房的楼梯。保留贝尔的接待位置或提供清楚的新位置提示。
- **旅馆二层**：客房走廊、少量可进入客房、清洁储物间。房门注明房间状态，住宿结算与实际休息位置对应。
- **驿站邮局**：临街柜台、信件分拣区、邮袋储藏及面向车马院的服务门。
- **车马院**：候车处、马厩、车辆停靠、修理棚、小型货物交接区；旅客和货物各有通路。

已有旅馆陈设和服务先盘点，确认楼梯是否真正连接可用楼层，再完成客房层。保留现有马车站、邮局和马厩的地点身份。

### 5.2 玩法与交付

优先完成“到店—询问或办理住宿—找到客房—休息—下楼返回街道”。饮食、邮件、旅客消息和车马业务随后按已有系统接入。地图快速传送沿用现有规则；马车、货运和护送各自说明真实用途及费用条件。

验收须保证前台与楼梯在进入后易于发现，客房能正确保存与结算，行李或货物不会堵住公共出口，邮局和马车原有业务仍可完成。

## 6. 建设四期：河港与工业区

### 6.1 工业建筑与运输组织

城市厂区按照“卸货—原料仓—生产车间—成品暂存—装运”组织空间，保持宽敞装卸院和连续运输通道。地区河港继续承担既有运单、签收和水利相关事务，城市厂区负责对应生产与交接，避免生成两份互不一致的货物账。

| 设施 | 施工重点 |
|---|---|
| 河岸长条货仓 | 装卸大门、货架与步行通道、称重和登记位置、原料与成品分区 |
| 锯木厂 | 原木堆、送料位置、切割工位、成品木料区；有必要时补检修平台 |
| 铸造车间 | 炉前、模具、冷却区、工具与工人休息处；让生产环节在布局上可辨 |
| 水力磨坊及锅炉房 | 动力设备、维护通道、操作与检查位置；保留已有用水和加工联系 |
| 船具修理棚及码头 | 修理台、零件存放、装船位置、办事柜台和安全步道 |
| 厂区生活配套 | 休息桌、饮水处、换班集合点；住宅与重货运输路线分开 |

### 6.2 玩法与交付

先选仓库和一间车间，交付一条“接收真实材料—加工或工程处理—核验结果—运输或领取”的完整流程，再扩大到相邻设施。已有仓库、锯木厂、铸造等具名人物与服务继续使用。

工程检查、设备维修和事故后恢复接续已有工程师玩法，新增设备必须绑定真实输入、输出和状态。建筑视觉上表现为长仓、机器和院落，不依赖普遍加层。

验收包括运输入口能找到、货物数量与运单一致、满包和重复领取有正确结果、加工和工程状态读档后保持，以及设备与货堆不会封住人行通道。

## 7. 建设五期：医舍修道院、市政与商会

本期分两个独立小批次验收，完成一处后再开下一处。

### 7.1 白鸢医舍与修道院

在既有地区扩充空间，保留诊疗室、档案室及梅菈、奥伦的事务。医舍入口连接接待与诊疗，病房设置较安静的内侧区域；配套药品储藏、药草庭院及修道院回廊，档案入口有独立说明。

首先把“送药或提交样本—诊疗或核验—等待复诊—回访取得结果”的既有过程对应到具体房间。病房、药草院和生活空间分步加入；新照料委托待规则完备后开放。

验收时玩家能找到两位办事人物，诊疗、样本来源核验和跨日复诊结果正确保存。医舍空间与草甸兽医服务保持各自用途。

### 7.2 居民议事厅与城市商会

议事厅沿用现有名称和公共职责：一层办理居民事务、公告及项目登记；二层按需求配置会议室、档案和工作人员空间。城市商会一层接待、货样及交付，后院安排货物交接，二层用于商议与资料查阅。

先整理已有柜台与事务，再把一条可完成的公共项目或商业交付放入空间。会议室需要实际讨论或事件内容，档案需要可查资料；新增楼层本身不授予玩家政治职位、金融能力或商会权限。

验收包括公共事务在一层可找到、会议与档案条件明确、项目和商业账目沿用已有规则、原任务可完成，楼梯及货物侧门互不阻塞。

## 8. 穿插建设：农舍与代表住宅

农舍作为玩家每天往返的起点，可在主线施工之间优先改善。先整理入口、厨房、工作与储物位置，再按升级需求增加卧室层或阁楼。升级前后必须保留睡觉、烹饪、储物及家具的使用与存档。

城市住宅先选一栋临街店屋和一栋花园住宅作为样板：店屋采用前店、后院、楼上住所；花园住宅采用会客、厨房、书房或卧室的生活分区。根据住户身份布置家具、活动和出入路线，再逐步推广到其他住宅。

验收重点是回家能直接找到床和常用设施，家具不会堵门；居民工作和归家位置符合建筑结构，访问限制有清楚反馈。房屋升级费用、家庭与长期照料按总体规划另行落实。

## 9. 施工组织与每期交付

### 9.1 推荐顺序

| 顺序 | 首个交付范围 | 后续扩充条件 |
|---|---|---|
| 一期：宫殿 | 三层主楼通行、房间用途与楼层牌 | 主楼路线通过后，施工一翼及后勤院 |
| 二期：大学 | 院落、教学入口、图书馆与一条学习研究流程 | 样板完整后扩专题研究和宿舍 |
| 三期：南门 | 旅馆两层与可结算的住宿流程 | 再扩邮局分拣、车马院及旅客生活 |
| 四期：港区 | 一个仓库、一间车间及真实货物流程 | 状态和账目一致后连通更多工厂 |
| 五期：公共机构 | 先医舍诊疗与档案，再议事厅和商会 | 各自验收后扩生活、会议与委托 |
| 六期：整体复审 | 地图提示、人物路线、存档、手机及单文件版 | 清理剩余封闭入口，登记远期内容 |

农舍和两栋代表住宅作为独立小批次穿插，不必等待公共机构全部建成。顺序可随已有职业内容调整，但正在施工的一条体验应先完成，再开启下一个大型建筑组。

### 9.2 开工前要确定的内容

每个小批次先交付平面草图，标明入口、出口、楼梯、门洞、主要家具、服务人物及封闭区；列出沿用与新增服务、任务状态和旧存档迁移规则。确认这些内容后再绘制外观并实现室内。

每次施工记录包含：改了哪些空间、玩家如何进入和使用、还未开放什么、验证结果及必要截图。新增场景、入口与楼层标识统一登记；旧入口、已到访状态、人物关系和任务进度有对应迁移。

### 9.3 统一验收标准

1. **能找到**：从正常地图入口到达，招牌、门、楼梯和楼层牌足以解释下一步。
2. **能走通**：实际按键和手机交互可进出、上下楼、进房间及返回原场景；不存在家具堵门或落入墙内。
3. **能使用**：本期承诺的服务有真实条件、动作、结算和反馈；物品不足、满包或重复操作处理正确。
4. **有生活**：至少展示与用途相符的人物活动或环境状态，关键服务人物可找。
5. **能保存**：旧档进入位置安全，新楼层及任务状态正确保存，原有任务与服务不退化。
6. **能发布**：多文件与单文件版本一致；必要缓存及绘制范围经过检查，手机尺寸下门名与操作提示清晰。模拟手机验证和实体设备验证分别记录。

完成标准是一个可进入、可理解、可使用并可保存的建筑组。图纸、外观和房间数量作为施工资料，不能单独代表完工。

2026-10-14 大学二期已在本地交付首轮：校园院落导览、主楼及图书馆二层、成对楼梯与“查阅—观察—核验—报告”研究流程已接入，详见[大学建设记录](university-construction.md)。长期学制、导师课程和宿舍入住仍待后续。

2026-10-14 南门三期首轮已在本地交付：旅馆两层、前台登记与客房过夜、邮局侧门、车马院导览及邮件回执流程已接入，详见[南门建设记录](south-gate-construction.md)。马匹购买、寄养与完整邮政制度仍待后续。
