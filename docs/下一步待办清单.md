## P0-1：湿地／河湾水位复查

- [ ] 在现有河湾或湿地现场加入一次复查，提供可发现的入口、联系人和明确的下一步。
- [ ] 复查读取真实工程阶段、已验收方案与湿地修复事实；未验收时不提前宣称工程已改善水位。
- [ ] 普通调查与辨迹／识矿提供不同线索，普通调查始终有安全、可完成的解法，不强迫学习指定天赋。
- [ ] 选择、结果和反馈写入唯一存档记录；重复打开、重复点击和读档不重复扣料、发奖或叠加效果。
- [ ] 验证未验收／已验收、两种工程方案、普通／天赋路线、失败拒绝、旧档和正常读档；源码与单文件都能完成。

完成标准：玩家能够到现场完成复查，并从记录与反馈中理解工程或湿地修复造成的实际变化。

## P0-2：周期养护接入地区日常服务

- [ ] 在磨坊或河港接入一项可再次使用的服务，让服务实际读取已验收方案与养护责任状态。
- [ ] 反馈区分未到期、到期、逾期、延期、已交接和已退出；不虚构尚未实现的停产、损失或处罚。
- [ ] 诺娅、马丁、河港面板和项目记录读取同一份事实；保守排水与兼顾通航的服务效果保持一致。
- [ ] 沿用现有养护周期与评价上限，不增加每日签到，不以反复打开窗口刷资历，不在交接或退出时抹除未处理事件。
- [ ] 验证服务实际结算、重复使用、跨周期、交接／退出和读档，确保物资、金币、评价与地区效果不重复叠加。

完成标准：验收后再次到访地区有实际用途，玩家能看懂当前由谁负责、何时需要检视及服务为何变化。

## P1：R4 季节与长计划

R3-D 收口后按以下顺序推进，先明确兼容方案，再实施。

- [ ] 统一四季年历和日期，定义跨季旧作物保护与旧档迁移。
- [ ] 农场照料委托提供逐日覆盖、材料与费用预览，再实现缺料中断、取消和恢复。
- [ ] 3／7 天计划逐日结算，关键事件到来时暂停；验证物品、金币、日期与照料结果守恒。
