# R3-C1：试运行预警与部分失败恢复

2026-10-15，本地实现，尚未提交推送。本轮承接工程施工闭环，完成试运行阶段的一条预防路线和一条失败恢复路线，不宣称整个R3-C已完成。

高风险取自已保存的水位、坡脚、淤积与方案，风险达到3级时，封闸试运行会记录预警，并留出次日一整天到闸基工作面(22,14)检查。报告、今日安排与N项目记录共用下一步说明；重复开窗、换场景、读档不生成事故。

现场检查20分钟、1体力。随后可交木材1、石料1加固（30分钟、2体力），或不收材料自行加固（90分钟、5体力）。预防完成后仍须按原规则跨夜验收，不要求发生本轮漏检事件。

若过了记录期限仍未加固，真实日结才把事件转为部分失败。玩家要回现场选择先保农田或先保通航的应急控水，再交材料补修或以劳动保底，补修隔夜后主动复查（25分钟、1体力），才能签署验收。原工序、机构经费和已付班工保留，不重发预算、不罚款、不自动补修或结案。验收前应急选择影响既有水位口径，验收后恢复由原工程方案决定。

安全记录保存在原项目的 `safety` 中，进度仍以原项目为准；旧档没有此记录时保留既有试运行或已验收结果，不追溯强加漏检。新的高风险试运行才开始预警记录。
