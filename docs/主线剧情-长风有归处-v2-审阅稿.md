# 《苔芽农场》主线剧情 v2：《长风有归处》

日期：2026-10-19。状态：创作审阅稿，尚未实装，不替换现行总规与既有存档事实。

已采纳进入[第九版总规](../游戏总体规划.md)，完整分场剧本与正式建设清单以总规§23—29为准。本稿保留为创作过程记录，不作为平行实施依据。

本稿接续“自由探索＋分阶段解锁主线”的方向，重新组织个人动机、地区篇章与任务标题。v1《未寄达的春天》保留为历史提案；其运输调查不再承担整部主线，可择取局部内容用于地区事件。

用户最新世界口径为“王国下的封国”。沿用白蔷薇大公领作为正式名称；王国、外部领地专名待定。旧总规中的“帝国”需在方案获采纳后另行统一。

## 一、主线的核心

玩家曾在旅途中得到一位测绘师的帮助。测绘师最后一封信约玩家在白蔷薇相见，谈及这里的一处可以安家的农场，还写道：“等最后一条路画完，我就回来。”

玩家抵达并开始经营苔芽农场，引路人却始终没有出现。一册寄存在白蔷薇的旧地图，将寻找引向王国不同地区。地图有些地方被划去，有些地方与现实不符；沿途居民对同一个人的记忆也彼此矛盾。

随着旅行，玩家发现被从正式地图中撤去的旧村落并未完全迁空。曾经的灾害、道路建设、迁居安排与一份被掩盖的报告，将引路人困在过去。寻找终于有了答案，但玩家还需要判断：该帮助他守住一条旧路，还是帮助那些人获得选择新生活的机会？

主题：人在远行中获得本领、关系与责任，也重新理解“家”意味着什么。

核心感情发展：想找到他 → 开始怀疑他 → 找到并理解他的错误 → 与他共同完成一件事 → 拥有自己的归处。

剧情规模从山谷走向封国省城、邻领、王直属河港、王都以及地图之外的旧山谷。农场持续作为返回点。每一章解决本地一段完整事件，同时推进对引路人与旧地图的理解。

## 二、主角与人物

### 2.1 固定与自由的边界

保留 Clawd 既有形象、玩家姓名和已取得的能力。新增固定关系只是一位曾帮助过主角的引路人，不规定玩家的父母、种族血统、出生地、全部童年或唯一职业；不加入失忆、王室血脉与天选能力。

新档将“来白蔷薇安家与赴约”作为开场动机。主角对这段往事有完整记忆，谜题是引路人的去向与选择，不是主角忘记了自己。

老档通过邮局收到补送的旧信启动寻人线，承认玩家已经在白蔷薇生活过。不能把已经营多年的存档重新称为“今天刚抵达”。

天赋、职业、正式权限和主线身份分开：

- 属性与天赋改变观察与处理手段。
- 职业经历改变入场理由、专业解法与人物评价。
- 正式资格决定签验、指挥等行为的权限。
- 主线共同身份始终是寻找旧友、亲历当地事件的行动者；依章节获得有限邀请或委托，不自动成为全权使者。

### 2.2 重点人物（新增姓名均为提案）

| 人物 | 作用与愿望 | 需要发生的变化 |
| --- | --- | --- |

| 莱娜，年轻邮务员 | 曾随家人迁居，对故乡只剩零碎记忆；希望证明父亲没有遗弃家人 | 从只想找一个正确解释，到能够听见父辈复杂的选择，并决定自己的去留 |

| 马丁（既有） | 见过伊文，愿意为实际解决问题的人说话 | 成为玩家初次靠本领获得信任的见证人，不只是发线索的 NPC |

伊文的测绘内容包括地形、旧驿路、居民点和通行季节，地图不是发光的魔法钥匙。星象、风、灯与钟声可以作为自然景观及命名意象，不据此引入新魔法体系。

莱娜在章节中会合、同行或分头行动。复杂伙伴跟随与战斗 AI 不作为第一版依赖。

## 三、因果底稿：供编剧使用

多年前一次山地灾害毁坏旧官道。伊文参与调查与现场救援，当时只能先开放其中一条救援通道。他的选择救下了一批人，也让另一批人等待更久；后者中有莱娜的家人。

伊文提交的正式报告要求继续搜救、保留居民联络与后续安置。为尽快完成迁建与新路结项，相关负责人将尚未完成的迁居写成已经完成，压下异议。伊文参与过紧急取舍，后来也因内疚与对机构的不信任，选择亲自补救而未能及时说清全部事实。他有被掩盖的意见，也有需要承担的选择。

旧山谷的人通过季节性山径、零散交易与亲友联系继续生活。他们从未从现实中消失，受到影响的是正式通路、稳定服务与被承认的居住安排。外围居民和商贩知道那里有人；不同机构掌握的情况不全，有些人则有意不把它记入正式报告。

如今新一轮整备计划拟封闭不稳定旧隧道，山谷仅存的冬季通路将受影响。安全风险真实存在，恢复旧路也非一句话可行。伊文前往山谷核验替代路线，并留下协助病人。他寄出的材料因涉及旧案被留置、转交或拒收，解释了玩家为何能沿途找到断裂的通信链。

王都篇揭示原始报告与现行整备安排的关系，暂缓有争议处置并授权现场核验。后段需要解决具体人的安全与通路，而非靠揭露文件就让所有事情自动恢复。

最终：愿离开者得到安全转移与有记录的安置；愿继续生活在当地者的长期安排，依据实测风险与后续维护条件审定。应急通路不等于一夜完成永久大工程。

## 五、完整任务目录与剧情

### 序章·风从旧信来

前半段应当温暖、具体。玩家与芽芽见面，整理住处，完成一次基本经营或等价入门工作。农舍逐渐可住，引路人的空位才开始让人惦记。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 一封信，一处屋檐 | 新档读伊文来信并安顿农舍；老档读补送旧信，承认已有家园，不重置教程与农务 |
| 泥土记得来时雨 | 完成一次初步生活成果；既有收成、入门工作或加工成果可被承认，让芽芽有理由记住玩家 |
| 水轮边的未竟之言 | 到磨坊询问伊文，协助一项现场问题；已修复磨坊则核对他留下的勘测标记，不重修 |
| 信末没有归期 | 从寄存物中取得旧地图，发现沿途留下的地名与一句未完成的话，正式决定寻人 |

结尾不是催玩家立刻离家。地图先指出白蔷薇城的一位联系人，寻人目标留在日志，玩家可以继续经营。

### 第一幕·满城蔷薇，谁记归人

玩家以已有本领或普通居民身份进入城市生活，沿伊文在大学、街区与宫城留下的痕迹寻找。有人称他认真，有人说他擅离职责，还有人不愿提起那次道路调查。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 城门内外，各有晨昏 | 到达城市并完成一项与既有经历相符的入场事件；提前到过则从已认识的人处接续 |
| 借一盏灯，读一页往事 | 在大学找到地图的旧版，实际对照地形、道路与批注，发现一片被正式撤去的居民点 |
| 花影不替人作答 | 在街区花园或接待场合询问三位立场不同的人；玩家需要分清亲见、转述与猜测 |
| 那年未落的签名 | 与莱娜初次合作，找出一份未被最终采纳的意见；她认出其中一处是自己的故乡 |
| 蔷薇以北，长路初开 | 依据已取得的材料获得有限随行／通行安排，准备出境；不授予外交与指挥全权 |

本幕反转：伊文与旧事故有关，莱娜认为他可能对父亲未归负有责任。主角第一次需要说明自己为何仍愿寻找他。

宫城接见根据玩家身份变化：专业玩家被询问技术或商路，普通玩家作为持信当事人陈述。无官职的玩家同样可以看见这一幕。

### 第二幕·群山不答，灯火犹温

王国的边界先通过手续、语言习惯、生活与意见差异被感知。山口另一边不是统一的“敌国”，而是王国内另一个领地。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 关山之外，有人候雪 | 经现有山口与边城合法通行，认识守路人与滞留旅人；职业影响协作办法 |
| 旧驿无人，炉火尚温 | 进入新增旧驿村，在空置驿舍找到近期生活痕迹，并帮助等候的家庭恢复取暖或炊事 |
| 不在地图上的晚餐 | 与迁居居民共同准备一餐，听他们讲各不相同的离乡经历，莱娜面对自己的片面记忆 |
| 山径两分，人心未定 | 实际走一段旧路：排险、辨路、请当地向导或合法护送均可，关键发现不依赖战斗胜利 |
| 请将灯留给后来的人 | 决定先帮助一个家庭安顿还是先追赶线索；通过分工保留后续道路，并得知伊文的材料被转往下游 |

本幕结束时，玩家确认旧山谷仍有人，但无法从此处直接进入其腹地：灾害后的路线已变化，当地向导只熟悉外段。前往河港是寻找近期通信与现行通路信息，不是为了绕远路凑时长。

### 第三幕·潮声尽处，尚有来信

空间转向海风、码头、夜航与远方来客。王直属河港有独立实景，不与白蔷薇河港混淆。剧情重点从“他去了哪儿”推进为“他这些年试图向谁解释什么”。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 风把远客送到岸边 | 抵达海关码头，完成一项港口协作以结识能查近期航路的人；已有商旅资历可直接获得引荐 |
| 千帆过后，名字犹存 | 通过船名、停靠地点与人物记忆核对伊文的行程，找到曾与他同行的医护人员 |
| 潮湿的纸，未说完的话 | 在滞留邮件与交接材料中还原通信顺序；真实操作是线索排序与内容辨别，不刷随机信件 |
| 今夜有人等船归 | 海岸突发险情，玩家组织岸上接应、设施操作或随合法救援同行；莱娜的判断首次改变行动安排 |
| 向群塔寄出一封信 | 得到近期通信副本：伊文承认自己当年的选择，但反对报告中“迁居已经全部完成”的结论，决定到王都追索原件 |

通过一段救援，让玩家亲身理解“现场无法同时做好所有事”，为之后评价伊文作准备。失败采用受限损失和补救，不随机杀死关键人物。

本幕也安排与故乡的联系：玩家寄信给芽芽，收到农场照料、季节与熟人近况；不能让农场在长篇主线中只剩一个传送点。

### 第四幕·高塔之下，众声如河

王都应有普通人的街巷、行当和夜晚。塔是档案院与报时钟楼的视觉地标，不代表玩家必须进入王宫觐见国王。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 初见王都，先问炊烟 | 在驿站街落脚，通过一段城市生活事件认识外来者如何安顿；经营与职业经历改变对话 |
| 钟声经过每一扇窗 | 向调查机构提交已取得材料，分别拜访退休测绘员、迁居家庭和执行人员，补足冲突事实 |
| 被折起的一页山河 | 在档案院操作地图与时间线，发现原报告要求继续安置，正式结项记录却将其写为完成 |
| 当众人说起故乡 | 参加一次有不同立场者出席的质询；莱娜可以陈述个人经历，主角只能对已知事实负责 |
| 愿你所见，足以为证 | 取得暂缓争议处置、开展现场核验的合法安排；接受有限任务，准备进入旧山谷 |

本幕的主要对立有真实理由：负责人认为旧隧道危险，继续依赖它会造成下一次灾难；玩家要追究的是隐瞒居民与拒绝真实安置，不能把合理安全问题一并否定。

他可以提出恢复伊文名誉、补发补偿并结束追查的安排。玩家仍能要求见到山谷里的人。即使接受部分救济，也不意味着自动放弃所有主张。

### 第五幕·地图之外，炊烟未冷

这是感情高潮。玩家依据最新测绘、向导与许可抵达山谷，看到地图上不再存在的屋舍、菜地与炊烟，终于找到伊文。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 群山深处，仍有人家 | 完成安全入谷，在居民生活中认识真实情况，不能进门就直接播放真相独白 |
| 你曾说过，会回来 | 与伊文重逢，莱娜找到父辈的下落；先安排人物相处，再决定如何谈当年的事 |
| 地图没有画出的名字 | 玩家协助一次照护、劳动或局部修复，分别听见愿留下与愿离开者的理由 |
| 旧路尽头，故人未远 | 走到当年的救援分岔处，结合现场、报告与亲历者解释当时的取舍，以及伊文此后的逃避 |
| 这一次，请听他们说 | 召集小范围居民商谈，决定应急行动的优先安排；主角可以不同意伊文，帮助不等于服从 |

关键转折：伊文想把原路重新打开，以此证明当年没有放弃任何人。但有居民已希望离开，家也不只存在于原来那几间房子里。

玩家寻找的那个人没有背叛全部承诺，也不拥有全部答案。主角需要形成自己的判断。伊文的变化通过一件小事表达：他把居民自己选择的去向写进新地图，第一次不再替他们填答案。

### 终幕·愿此长路，终有归人

在玩家确认准备后才启动有明确期限的应急行动。现场核验发现天气变化将使季节性通路难以继续使用，必须在已说明的窗口内转移需要照护的人、维持联络并开放经确认的临时安全路线。

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 出发以前，先道珍重 | 明确要帮助的人、任务范围、接应地点和退出办法；安排农场与同行人员，不偷快进 |
| 今夜群灯，不为一人 | 联系沿途结识的居民、医护、工匠和守路人，玩家选一项亲自承担，其他由有依据的安排执行 |
| 循着风，走到天明 | 工程排险、民用转移、山径引导或合法军事护送形成不同操作段落，完成最后一段通路 |
| 请把他们的名字留下 | 实际核对到达人员与交接，公开补正旧记录并启动应有问责；不能以高属性洗去事实责任 |
| 从此，地图上有了归途 | 获准保留经确认的临时联络与后续维护安排；愿迁居者获得具体安置，长期工程另立计划 |

高潮通过人物各自完成约定体现：马丁让面包按时送到，海港医护来接需要照护的人，莱娜投递的不再只是别人代写的消息，伊文按照居民的选择领路。

主角不需要独自挽救整个王国。其作用是亲历、连接、提出办法并承担一份具体行动，让彼此隔绝的人终于能够一起完成这件事。

结局差异主要来自迁居选择、证据完整度、救援准备与关系处理。可先执行紧急保护，长期居住与通路审批在尾声交代条件；不存在一句话永久开放危险山路的万能结局。

### 后日谈·明日仍有花开

| 任务标题 | 剧情与玩家动作 |
| --- | --- |
| 一路捎来的小事 | 回访或读到沿途人物的近况，收到种子、食谱、修订地图等与实际经历有关的小礼物 |
| 门前有客，桌上有灯 | 回到小镇与农舍，和芽芽、伊文或莱娜谈今后的去向；出席者及话语随选择变化 |

伊文可以继续测绘或参与后续维护，莱娜有自己的生活方向。主角可接一份有边界的工作，也可回农场，不以拒绝官职判定低等结局。

## 六、解锁门槛与自由探索

### 6.1 门槛规则

不新增“冒险等级”来复制已有角色成长。主要使用前章完成、真实生活经历、已知线索和合法通行事实；等级只在实际试玩证明需要时辅助校准，暂不把未经测算的等级数字写成硬要求。

| 篇章 | 前置 | 与自由发展的接法 |
| --- | --- | --- |
| 序章 | 新档开局，或老档接收补送旧信 | 保留原职业与世界状态 |
| 第一幕 | 序章完成；取得任意一种入门生活成果 | 工程、商旅、巡林、经营任选其一，已有成果直接计入 |
| 第二幕 | 第一幕结束并取得对应通行安排 | 民用随行可完整通关，军事是自愿分支 |
| 第三幕 | 第二幕得到通信去向与航路信息 | 商旅经历可改变引荐与费用来源；无经历者有本章劳动协助路线 |
| 第四幕 | 第三幕取得可提交的材料 | 学术、工程、商旅、普通当事人有不同发言方式 |
| 第五幕 | 王都批准现场核验并取得安全路线 | 接受有范围的协助，完成本章行动准备 |
| 终幕 | 与居民商谈完成；应急条件核验；玩家确认启动 | 有期限的行动此时才计时；准备存在公共支持与基础保底 |
| 后日谈 | 终幕完成，包括可恢复的部分结果 | 不以全收集、爵位或28天任期作为看结局门槛 |

门槛 UI 应显示具体条件及已完成项；可以提前显示“尚待某封来信”，但不能让玩家不知道下一章为何没出现。职业条件使用“任一”，不要求全修。所有保底办法都必须实际可玩。

### 6.2 提前探索与完成

地图大部分探索独立于章节。人物日常、地区任务和普通服务先存在，主线解锁的是新事件、特定接见和有理由管制的现场。

每段主线至少检查三种情况：初访；来过但未完成相关事务；已完成相关事务。

例如：磨坊已修，不再安排设备故障；以旧修理记录核对伊文批注。玩家已到省城，不重演初次进城；熟人直接来找。已有巡防资格，不再称普通见习者；但没有本次任务授权就不能调兵。

旧山谷普通外围可提前探索，真正危险内段需要近期路线核验与许可。即便通过合法探索取得晚期线索，也应存为已发现；提前见到伊文的可能性必须在关卡设计时明确处理，不能让他无理由隐形。若原计划无法可靠避免合法提前抵达，就增加“已重逢、待补全旧事”的章节接续，而非重演惊讶和找人。

### 6.3 解法与事实

同一关键发现应有基础路线；属性与专业提供信息细节、成本差异、人物反馈和操作办法。不能让未点某个天赋的玩家永久缺失主线真相。

关键选择检查玩家是否知情、承诺什么、实际完成什么。不用高幸运决定核心线索，不用高智力把道德冲突直接判成唯一正确答案。

地区事件引用工程、照护与货运的原有事实。主线只记录自身事件、人物选择和证据来源，不能复制一套磨坊是否修复、部队是否受命、货物是否到达的平行账本。

## 七、标题与任务界面

命名借鉴章节式冒险的意象、节奏和回响，全部采用本作新写标题，不挪用其他游戏现成任务名与专有体系。

反复出现的意象各有用途：

- 信：约定、误解与重新表达。
- 地图：被记录的世界与真实生活之间的距离。
- 灯火：陌生地区中具体的人与相互接应。
- 风：出发、消息、变化和回程。
- 屋檐与炊烟：玩家真正关心的日常生活。

标题避免全部同为四字成语、全部使用“风与某物”、或每个标题都堆花、月、星、雪。短任务名如《信末没有归期》，与长名如《今夜群灯，不为一人》穿插使用。

主标题不承担导航。界面示例：

> **潮湿的纸，未说完的话**
>
> 在王直属河港的邮件留置处，与值班邮务员核对伊文来信的交接记录。
>
> 地点：王直属河港·邮务所。已知线索：伊文近期来信副本。

下一步、联系人、地点与前置必须具体。任务面板不能只写“循风而去”“静候命运”。大幕名不应剧透伊文仍然活着或最终责任归属；第五幕后才展示对应标题。

## 八、制作和验收

本稿提出的王都、外部河港、旧山谷、新人物和主线框架均未实现。现有地区任务能复用其舞台与部分操作，不能按名字相近直接算作剧情完成。

第一切片制作序章与第一幕，目标约60分钟：验证主角动机、莱娜初见、地图矛盾、一次身份差异和提前完成接续。切片必须有实际探索、操作、对话与选择，不能60分钟全读窗口。

之后制作第二、三幕并跑通旅行与农场照料；再制作王都、重逢和终幕，让前段线索都有后文解释。三处反转需提前埋下可回看的事实：伊文与旧事故有关；旧村落仍有人；伊文本人的执念也需要改变。

时间目标是约275分钟单路线有效内容，正式验收至少3小时普通首玩。测试剔除挂机、重复赶路、刷经验、重复农务、等待作物与互斥路线；剧情资料已有成果的老档可以更短，单独计时。

需覆盖：不参加军事、不修完整工程职业、先探索后主线、已有高资格老档、任意季节接取、读档与单文件版、触屏操作及期限恢复。若合法提前探索能改变章节顺序，必须有真实接续对白与任务状态。

未验证时长不写成已达标。若不足，增加人物事件、现场解题与后果段落；不增加强制停留、刷取数量和无内容行走距离。
