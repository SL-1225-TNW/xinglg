# 玩家视角审查与第八版总规改写依据

日期：2026-10-12。对象：本地工作区开发页，含室内门改动；不是线上版本核验。

## 判断

目前最完整的循环是农场经营与基础主线：种植、照料、资源、交付、修桥、钓鱼、制作、关系与保存可以连起来。扩展地区已经有服务和合同样板，但“个人怎样成长、去哪里学天赋、如何装备刀剑、怎样独立走一条职业”的体验还没有闭合。

因此第八版把开发顺序改为入口与状态 → 个人成长与独立入门 → 个人刀剑与危险选择 → 职业/地点生活 → 季节与长期计划 → 制度和完整版本验收。世界与军事方向继续保留，不以继续扩图代替个人成长。

### 自然基础主线

`node tests/run-main.mjs` 本次运行 **123 项通过，完成于第 14 个游戏日，控制台零错误**。

实际推进内容：从初始 50 金和种子开始，逐格翻地/播种/浇水；正常采集木石和睡觉；收获萝卜、土豆并完成前四项委托；用真实材料修桥得到钓竿；实际抛竿、按键钓鱼；制作放置木箱和洒水器；聊天/赠礼达到果酱罐条件；种植草莓、加工和出售果酱；最后刷新核对日期、金钱、物品、任务、关系与设备状态。

本脚本未注入高级资源、鱼获、证书或主线完成状态。它会根据可走地图计算路线并驱动键盘，知道人物/设施的目标坐标，所以通过不等于陌生玩家无需帮助就能找到全部步骤。脚本通过 14 天也不表示每个世界日都按自然时钟完整等候。

试玩过程中，日常逐格浇水和重复材料采集占据大量动作；洒水器、加工和关系的解锁提供了真实变化。由此保留农场循环，并优先增加可预览目标、合理工具便利和经营经验，不能把基本浇水便利锁到天赋之后。

### 扩展内容的证据边界

磨坊/草甸、湿地/D/E、室内门、天气和存档以本会话前一轮专项测试及维护中的验收说明作为依据；本次没有将全部扩展职业从新档再自然玩一遍。专项夹具验证不能证明独立职业入口没有循环依赖。

参考：[室内门记录](indoor-doors-plan.md)、[阶段 C/D/E](phase-cde.md)、[D 复审](phase-d-review.md)、[接手审查](takeover-review-2026-10-11.md)。这些是各自基线与范围的证据，不能合并称为整个 RPG 已完成。

## 改写后的重点

| 观察/缺口 | 第八版的具体调整 |
|---|---|
| 天赋与个人武器没有入口也没有核心规则 | 第 3—6 节定义角色四页、点数预算、十个首批节点的用途、免费武器训练与装备/升级流程 |
| 玩家看到探索 Lv，却缺角色成长 | 角色经验、探索阶位、职业资历、信任、职位和荣誉分开 |
| 一开始已有多个地区提示 | 今日安排只突出家务、当前追踪和一个可选机会；远方预告可关闭 |
| 角色有资历/权限样板，独立入门不完整 | 小镇工程、商旅、巡林各一条新档可走通的工作；禁止交叉循环前置 |
| 已有很多场景，却不一定有持续生活 | 重点地点逐项安排日常用途、人物、事件与保存的可见后果 |
| 工程事故/岗位还偏按钮样板 | 补真实预警、施工、机构预算、责任、失败恢复及后续工作 |
| 时间、季节和长期照料缺席 | 保留现有日常节奏，先完成委托/计划和经济过渡，再引入四季及任期 |
| 旧 A—E 阶段容易被理解为总规完成 | 使用 R0—R5 玩家体验里程碑，明确首版范围、缺口总账及四层验收 |
| 配套文档仍指向旧版且部分 README 地区描述是合并前玩法 | 更新现行入口与章节链接，说明旧排期的历史范围，并修订磨坊/草甸说明 |
