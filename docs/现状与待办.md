- 同一剧情事实共用任务完成键与奖励键，重复进出不重复发经验。

1. 剧情正文只从总规 §27 分场稿取，不另写一份。
2. 新入口先过「不占用工具目标格」与「落脚点不压下一张图的出口格」两条。
3. 存档字段一律走 `newXxxState()` + `normalizeXxx()`，不升 `SCHEMA_VERSION`，旧档只补默认值。
4. 专项套件要同时支持 `--single-file`，并挂进 `tests/run-ci.mjs` 的浏览器层与单文件复跑列表。
5. 同步四处：主线日志、今日安排、证据面板、文档（总规 §28、待办清单、状态表、交付记录）。
