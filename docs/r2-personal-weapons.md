# R2 · 个人刀剑与危险选择

2026-10-13。对应第八版 R2，入口是 `index.html` 或重新构建的单文件版。个人装备、生命与事件保存在 `state.personal`，角色经验仍只使用 `state.char`；军事编队与机构预算不参与。

## 从新档怎样玩

1. 按 P → 武器 →「第一次自卫训练 · 查看 / 追踪」。今日安排显示小镇训练牌 (17,13)。全天免费，不要求修桥、城门证或军事资格。
2. 在训练牌旁按 E，分别免费试剑、试刀。走近并朝向假人，空格命中，Shift 闪避，再按「撤回安全区」。手机使用方向键、攻击、闪避与撤回按钮。
3. 两形制各练习命中和闪避后，任选旧刀或旧剑领取。另一形制可在训练牌旁从武器页免费补领，只能各持有一把。工具位与背包容量不受影响。
4. 角色 → 武器可装备、换用、命名与委托升级。Q 收拔；只有武器模式的空格执行攻击。闪避默认 Shift，可在武器页改 X 并保存。
5. 旧矿山一层南侧 (14,20) 的警示牌提供矿穴和旧河道两段短支路；普通采矿不必进入。旧刃就能处理，也能选择「绕行标记」。每个事件无论驱离或绕行，都给 35 金和 10 危险经验，仅结算一次。

小镇工坊新增铜矿3 + 煤1 → 铜锭1、铁矿3 + 煤1 → 铁锭1；每批30分钟、2体力。煤24金、木炭36金可在工坊购买。城市霍尔提供铁锭2 + 木炭1 → 钢锭1，同样30分钟、2体力；原有城市铸造批量配方保留。刃材试验消耗铁矿2、木炭1、30分钟、3体力，发一次60经验，并开启精钢整修。

升级顺序固定，保留名字与纪念绳结。地点、原武器阶段、材料、金币和剩余时间一起校验，失败不扣费；熔炼先检查完整产物能否放入背包。陨铁没有购买按钮。

## 遭遇、恢复与暂停

剑：0.70秒间隔、1.00系数、前方1.3格窄范围。刀：0.60秒、0.85系数、前方1.1格宽范围。普通敌人48生命、1防御，旧刀单击6伤害、旧剑7伤害。动作不扣农事体力，空挥不发经验。

矿穴生物先举爪，0.75秒预警后攻击标记位置；旧河道生物先伏身，0.9秒预警后冲向标记位置。每次仅一个敌人，活动限于独立短支路，不会追进生活地点。受击8生命，0.6秒保护；闪避冷却1.6秒、移动约1.2格、保护0.16秒，不穿墙。

生命上限 `60 + 4 × (健康−5)`。面包明确恢复12生命，均衡饮食向下取整为13；其他食物仍只恢复原有体力。睡觉免费恢复生命。归零退回入口，恢复半血、推进60分钟，保留钱物、武器与经验；时间到日终时正常结算。主动撤回不扣费，未完成敌人重置。两间短支路接入统一南侧双格门，可步行或在门旁按E退出，门洞、提示与落点共用配置。

菜单、对话、钓鱼、切后台、场景切换与结算都会暂停危险模拟。冷却、无敌、硬直和敌人预警都使用模拟时间。遭遇中即使打开菜单也不能洗点。途中保存并重开会回到对应安全入口，保留当前血量、训练记录及已结算事件，不保留临时敌人或试用装备。

| 节点 | 实际场景 |
|---|---|
| 专注研读 | 矿山一层矿样研究减时10%；智力每高于5一点再减1%，合计最多25%，最终分钟向上取整 |
| 工艺理解 | 工坊水泵分析有效智力+2、最多20；达到10可核对松栓与用水记录，跳过往返询问，仍须紧固与交付；原保底流程保留 |

| 识矿 | 一层(4,3)、二层(9,8)各设4份富集矿脉，附近可见金色迹象，支路牌可读位置；仍须亲手采集 |
| 沉着 | 0.35秒受击硬直额外减少10%，与胆量合计最多25% |
| 挺身而出 | 完成入门水泵紧固试水后在工坊接下水泵值守，花15分钟/3体力，次日20分钟/3体力复核，领取一次25金、60经验和工程路线记录；洗点仍保留责任与复核入口 |
| 节省力气 | 沿用R1，每日最多节省10体力，记录最近减免 |
| 均衡饮食 | 体力与明确食物生命恢复+15%，向下取整、各自封顶 |
| 顺手所得 | 普通森林/矿山资源额外1份概率+3个百分点，含幸运合计最多17%；每节点再生周期只检定一次，结果按节点和世界日固化 |
| 好时相逢 | 在小镇集市花5分钟与居民分享见闻，得普通野莓1份；每七个世界日一次，满包不扣时间、不消耗机会 |

所有入门节点在学习前检查属性至少8与可用天赋点。最近实例显示在天赋卡中；角色经历显示训练、遭遇解法与值守责任。当前等级上限仍为10、最多获得3天赋点；十节点开放不等于能同时学习十个。后续十五节点不出售。健康增加生命上限，体力上限仍保留原规则。
